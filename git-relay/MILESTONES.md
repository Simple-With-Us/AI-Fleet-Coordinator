# Milestone GitHub commands

Default-off own-App list/get/create/update/delete with existing issues permission
ceilings and repo/action allowlists.  No raw endpoints or account changes. 
Titles are nonblank and bounded at 1024 UTF-8 bytes, descriptions at 32 KiB;
secret scanning happens before any network or durable ledger.  Delete is irreversible
and this code adds capability, not permission to execute it.  No live milestones were
changed.  Due dates, optional/partial updates and issue milestone assignment remain
outside this first bounded family.  Existing UNKNOWN holds and no-replay behavior apply.
