# Repository tag and language metadata

Two default-off own-App reads. Tags use contents:read, perpage1-50/page1-1000,
name+commitSHA projection only, conservative has_more from original page length.
Languages use metadata:read, up to100 language names and safeinteger bytecounts;
no percentage, contributor identity, filecount or fresh code-audit claims.
Strict closed parsed input/receipts, explicit known-pattern credentialname refusal,
no source bodies or arbitrary URLs. Inherited issue relation reads remain separate.
No grants/connections/mutations/deployment. Annotatedtagcontents not fetched.

Source: https://raw.githubusercontent.com/github/rest-api-description/main/descriptions/api.github.com/api.github.com.json
