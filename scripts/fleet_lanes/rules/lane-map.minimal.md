Lane Map (owner 2026-10-09; docs/protocols/lane-map.md in AI-Fleet-Coordinator): a git checkout lives only in ~/apps/lanes/<Repo>/minimax-<slug> (your task lane, branch minimax/<slug>; <Repo> is the repo's folder name under ~/Code exactly as spelled there, such as Congress.Trade; create it with `~/apps/lane new <app> <slug>`, which needs AGENT_SEAT=MM, never guess your seat), in ~/apps/lanes/<Repo>/review-pr-<n> (read-only PR checks), or in ~/Code/<Repo> (the human's integration tree, never edit it or put a worktree inside it).
Never clone a fleet repo, or add a worktree of one, in /tmp, /private/tmp, /var/tmp, $TMPDIR or /var/folders; scratch files and throwaway test repos there are fine.
Folder names use the whole seat name (minimax, never mm).  Old lanes in ~/apps/lanes/<prefix>/, _managed or _review stay until the migration moves them, and flat ~/apps/<prefix>-<seat> lanes retire where they are; do not create new ones in any old place.
